# Changelog

## 1.1.0

- Fondo automático desde varias carpetas, con subcarpetas opcionales.
- Intervalo configurable, orden aleatorio sin repetición inmediata y opacidad.
- Panel propio en Appearance & Behavior → Antigravity Visual Pack y acceso en Tools.
- Cambio manual a la siguiente foto, recuperación del fondo anterior y ajustes persistentes.
- Exploración fuera del hilo de interfaz y pruebas de rotación con archivos reales.
- Se conserva el acceso al selector nativo de una imagen individual.

## 1.0.0

- Initial unofficial port for IntelliJ IDEA 2026.2.x.
- Red One Dark Pro: Dark, Dark Bordered, Mirage and Mirage Bordered.
- Material Icon Theme: 1,238 SVG icons with file, folder and language associations.
- Shortcut to native background-image settings.
- Offline build using a local IntelliJ IDEA SDK; resource and mapping checks.

The plugin compiles against IntelliJ IDEA 2026.2.3. Visual behavior inside the IDE
has not yet been verified. See README.md for adaptation limits.
